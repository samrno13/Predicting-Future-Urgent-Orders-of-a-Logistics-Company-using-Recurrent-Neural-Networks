
**Predicting Future Urgent Orders of a Logistic Company using Recurrent Neural Networks**

**Author:** Samuel Reano

**Format:** Jupyter Notebook (.ipynb)

**Overview**

A time‑series project using Brazilian logistics data to predict urgent orders. Built a Naive baseline and a stacked GRU model. Baseline used values from two weeks prior; GRU predicted 7 days using a 14‑day look‑back. Evaluated both with RMSE and MAE, with GRU outperforming.

**Contents**

* Naive Baseline Model
* Gated Recurrent Unit Model
* Accuracy Results
